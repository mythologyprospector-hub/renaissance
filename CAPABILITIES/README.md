### Learn — Recognized Capability, Implementation Open

**Learn** is now recognized as a Renaissance system capability through an explicit contract in `CAPABILITIES/LEARN_CONTRACT.md`.

The contract establishes a responsibility distinct from information delivery: increasing durable human capability, with explicit separation of exposure, performance, and transferable capability.

No implementation repository is designated yet. A concrete workflow test in `CAPABILITIES/LEARN_MODEL_TEST.md` shows that the responsibility is materially different from Episteme, AI Foundry, Praxis, and Organs, particularly around learner state, scaffolding, feedback, adaptation, and transfer assessment.

The architectural result is deliberately restrained:

- Learn is a recognized responsibility.
- No learning algorithm or repository is prescribed.
- Existing instruments remain themselves.
- A new implementation should be built only if real workflows demonstrate that these responsibilities cannot be coherently provided by existing instruments without distorting their purposes.
