# Renaissance

Renaissance is an open, human-centered project to increase humanity's ability to understand, explore, create, and flourish.

This repository is the constitutional and foundational home of Renaissance.

It does not contain the whole Renaissance system. Software projects such as `organs` and `episteme` may implement capabilities governed by this foundation.

## Status

This repository is in its initial constitutional formation.

The documents here deliberately distinguish established canon from proposals and unresolved questions. The project is expected to evolve.

Start with `STATUS.md`, then `CHARTER.md`, `CONSTITUTION.md`, and `DECISIONS/0001-initial-foundation.md`.

Nothing becomes canon merely because it appears in a document. Constitutional authority is established through the documented decision process.
